# DBMS Lab

DBMS Lab — образовательная платформа для изучения внутреннего устройства PostgreSQL.

## Стек

- Frontend: Next.js, React, TypeScript
- Backend: ASP.NET Core
- Database: PostgreSQL
- Infrastructure: Docker Compose

## Зафиксированные версии

- Node.js: 24.21.0 LTS
- .NET / ASP.NET Core: 10.0 LTS
- PostgreSQL: 18.6
- Docker Compose: Compose Spec
