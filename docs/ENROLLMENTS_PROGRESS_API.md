# Запись на курс и прогресс

Все методы требуют `Authorization: Bearer <accessToken>` от существующей учётной записи любой роли. ID пользователя определяется на сервере. Маршрутов для чтения или изменения чужого прогресса нет.

## Запись на курс

`PUT /api/me/enrollments/{courseId}` не требует тела. Курс должен существовать и иметь статус `Published`. Ответ первой, повторной и конкурентной записи — `200 OK`:

```json
{
  "courseId": "10000000-0000-0000-0000-000000000001",
  "enrolledAt": "2026-11-24T10:00:00Z"
}
```

Повторы возвращают исходную дату записи и не создают дубликаты. Для чернового и архивного курса возвращается `403`, даже если пользователь был записан ранее.

`GET /api/me/enrollments` возвращает `200 OK` и массив собственных записей, упорядоченный по названию курса и ID. Архивные курсы сохраняются в списке. Пустой список — `[]`.

```json
[
  {
    "courseId": "10000000-0000-0000-0000-000000000001",
    "courseTitle": "Основы PostgreSQL",
    "enrolledAt": "2026-11-24T10:00:00Z"
  }
]
```

## Изменение прогресса

`PUT /api/me/lessons/{lessonId}/progress` принимает JSON:

```json
{"status":"Completed"}
```

Обязательное поле `status` принимает строковые значения `NotStarted`, `InProgress`, `Completed` (без учёта регистра). Числа, числовые строки, неизвестные значения, `null`, отсутствие поля и посторонние поля отклоняются с `400`. В ответе используются указанные канонические названия. Явный сброс статуса, в том числе из `Completed` в `NotStarted`, разрешён.

Урок должен быть опубликован, его курс — иметь статус `Published`, а текущий пользователь — быть записан на этот курс. Отсутствие любого из этих разрешений даёт `403`. Предпросмотр автора или администратора не заменяет эти условия.

Успех — `200 OK`:

```json
{
  "lessonId": "40000000-0000-0000-0000-000000000001",
  "status": "Completed",
  "updatedAt": "2026-11-24T10:05:00Z"
}
```

Повтор того же статуса сохраняет прежний `updatedAt`. При конкурентных изменениях с разными статусами побеждает последняя запись в БД, все допустимые запросы возвращают `200`. Время в ответе — дата сохранённого изменения, а не средство упорядочивания конкурентных запросов клиентом.

## Просмотр прогресса курса

`GET /api/me/courses/{courseId}/progress` доступен только записанному пользователю. Ответ `200 OK`:

```json
{
  "courseId": "10000000-0000-0000-0000-000000000001",
  "completedLessons": 1,
  "totalLessons": 2,
  "progressPercent": 50
}
```

В расчёте участвуют только уроки с `IsPublished = true`. Процент округляется до целого, при отсутствии опубликованных уроков все значения равны нулю. Эта сводка не является снимком курса: изменение состава опубликованных уроков меняет знаменатель, но не удаляет накопленные записи прогресса.

После архивации собственная сводка и список записей остаются доступны с `200`; записываться повторно и изменять прогресс нельзя (`403`). Архивация не меняет флаги уроков и не удаляет прогресс. Перезапуск backend с той же PostgreSQL сохраняет данные.

## Ошибки

| Код | Условие |
| --- | --- |
| `400` | Некорректный GUID, JSON или статус. `ValidationProblemDetails` содержит `errors`. |
| `401` | Нет действующего JWT или соответствующей учётной записи. JWT проверяется до поиска ресурса и валидации тела. |
| `403` | Курс/урок недоступен или пользователь не записан. |
| `404` | Запрошенный курс или урок отсутствует. |
| `500` | Неожиданная ошибка сервера. |
| `503` | Временная ошибка подключения к БД или таймаут. |

Ошибки действий возвращаются как `application/problem+json` с `status`, `title`, `detail` (при наличии), `instance` и `traceId`. Валидация также содержит `errors`. Отказ JWT-аутентификации может иметь пустое тело и заголовок `WWW-Authenticate: Bearer`.

```json
{
  "title": "Access denied",
  "status": 403,
  "detail": "The course is not published.",
  "instance": "/api/me/enrollments/10000000-0000-0000-0000-000000000001",
  "traceId": "request-trace-id"
}
```

**Изменения контракта:** вместо прежнего `{error,message,statusCode}` используется ProblemDetails; непубликуемый курс теперь даёт `403` вместо `400`; конкурентная запись возвращает `200` вместо уникального конфликта; статус прогресса обязателен и принимает только строки. Успешные DTO и маршруты сохранены.
