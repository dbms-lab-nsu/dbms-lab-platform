# API управления курсами автора

Для всех маршрутов передавайте `Authorization: Bearer <accessToken>`. Нужна роль `Author`. Администратор с этой ролью также управляет только своими курсами. Владелец определяется по ID из JWT и сохраняется при создании курса.

| Метод | Успешный ответ |
| --- | --- |
| `POST /api/courses` | `201 Created`: новый курс в статусе `Draft`. Заголовок `Location` указывает на `/api/courses/{id}`. |
| `PATCH /api/courses/{id}` | `200 OK`: курс с обновлённым названием или описанием. Можно менять курсы в статусах `Draft` и `Published`. |
| `GET /api/author/courses` | `200 OK`: массив собственных курсов всех статусов. Сортировка по названию, затем по ID; без фильтров и пагинации. Если курсов нет, возвращается `[]`. |
| `POST /api/courses/{id}/publish` | `200 OK`: курс переведён из `Draft` в `Published`. |
| `POST /api/courses/{id}/archive` | `200 OK`: курс переведён из `Draft` или `Published` в `Archived`. |

## Создание и редактирование

Передавайте JSON с `Content-Type: application/json`. Для создания нужны оба поля:

```json
{
  "title": "Основы PostgreSQL",
  "description": "Введение в устройство PostgreSQL"
}
```

В `PATCH` достаточно одного поля, например `{"description":"Обновлённое описание"}`. Пропущенные поля и статус сохраняются. Пробелы по краям обрезаются. Название должно содержать от 1 до 200 символов после обрезки, описание — быть непустым. Пустой объект при редактировании, `null`, нулевой символ и посторонние поля, включая `authorId` и `status`, отклоняются.

Пример ответа на создание; остальные операции записи и элементы списка используют этот же формат:

```json
{
  "id": "27ecd186-9f07-41cb-9efa-74f910faa227",
  "authorId": "143c8e4a-a413-4f8d-801f-d13fe49b10b3",
  "title": "Основы PostgreSQL",
  "description": "Введение в устройство PostgreSQL",
  "status": "Draft"
}
```

## Публикация и архивация

Запросы `publish` и `archive` не требуют тела. Для публикации у черновика должны быть корректные название и описание и хотя бы один урок с непустыми названием и содержимым. Урок должен принадлежать курсу по цепочке «модуль → тема → урок». Все заполненные уроки получают `IsPublished = true`, незаполненные остаются скрытыми. Статус курса и флаги уроков сохраняются вместе. Создание и редактирование учебного содержимого в эти методы не входят.

При архивации уроки и их флаги сохраняются, но курс исчезает из публичного каталога и становится недоступен обычным читателям. Автор и администратор сохраняют действующие права предпросмотра. Архивный курс нельзя редактировать, публиковать или повторно архивировать.

## Ошибки

| Код | Причина |
| --- | --- |
| `400` | Некорректный GUID, JSON или значения полей. Ответ содержит `errors`. |
| `401` | JWT отсутствует, недействителен либо соответствующая учётная запись не найдена. |
| `403` | Нет роли `Author` или курс принадлежит другому автору. |
| `404` | Курс с указанным ID не найден. |
| `409` | Недопустимое изменение статуса, редактирование архива или курс не готов к публикации. |
| `500` / `503` | Внутренняя ошибка или временная недоступность БД. Подробности остаются в серверном журнале. |

Ошибки контента возвращаются как `application/problem+json`. Ответы `401` и `403`, возвращённые при проверке JWT и роли до вызова контроллера, могут быть без тела.
