# API учебного контента

API предоставляет каталог опубликованных курсов, карточку курса, дерево
`Курс → Модуль → Тема → Урок` и содержимое опубликованного урока.

## Формат

Ответы с данными имеют формат
`application/json`, названия полей — `camelCase`. Идентификаторы — GUID.
Идентификаторы в примерах условные: при выполнении запросов используйте значения из своей БД.

## Методы и доступ

| Метод | Назначение | Требуется JWT |
|---|---|---|
| `GET /api/courses` | Страница каталога опубликованных курсов | Нет |
| `GET /api/courses/{id}` | Карточка опубликованного курса | Нет |
| `GET /api/courses/{id}/structure` | Модули, темы и краткие данные уроков курса | Нет |
| `GET /api/lessons/{id}` | Содержимое опубликованного урока | Да |

В каталог, карточку и структуру попадают только курсы со статусом `Published`.
Курсы `Draft` и `Archived` возвращают `404` при обращении по ID, в том числе для
автора и администратора.

Урок возвращается, только если одновременно выполнены два условия:
`Lesson.IsPublished = true` и статус его курса — `Published`.
При запросе структуры неопубликованные уроки исключаются из дерева.

Любой пользователь с действующим JWT может читать опубликованные уроки.
Дополнительных ограничений по роли или записи на курс в этих методах нет.
Для запроса урока передайте заголовок:

```http
Authorization: Bearer <accessToken>
```

### Метаданные элементов

DTO содержат общие поля:

| Поле | Тип | Значение |
|---|---|---|
| `id` | string (GUID) | Идентификатор элемента |
| `title` | string | Название |
| `type` | string | `course`, `module`, `topic` или `lesson` |
| `requiresAuthentication` | boolean | Требуется ли вход для доступа к элементу через API |

Для публичных метаданных курса, модуля и темы `requiresAuthentication = false`.
Для урока — `true`, включая его краткое представление в публичной структуре.
Это требование доступа к содержимому, а не результат проверки текущего пользователя:
значение остаётся `true` и в ответе на запрос с действующим JWT.

## GET /api/courses

Возвращает `200 OK` и объект `CourseCatalogDto` со страницей каталога.

### Параметры запроса

| Параметр | Тип | По умолчанию | Допустимые значения |
|---|---|---|---|
| `page` | integer | `1` | От `1` до `2147483647` |
| `pageSize` | integer | `20` | От `1` до `100` |

Оба параметра необязательны. Нумерация страниц начинается с 1.
Неверный формат или выход за допустимый диапазон возвращает `400 Bad Request`.

Курсы сортируются по `title`, затем по `id` по возрастанию.
Пагинация применяется после фильтрации опубликованных курсов и сортировки.

### Пример запроса

```http
GET /api/courses?page=1&pageSize=20
Accept: application/json
```

### Пример ответа

```json
{
  "items": [
    {
      "id": "10000000-0000-0000-0000-000000000001",
      "title": "Основы PostgreSQL",
      "description": "Введение во внутреннее устройство PostgreSQL",
      "type": "course",
      "requiresAuthentication": false
    }
  ],
  "page": 1,
  "pageSize": 20,
  "totalCount": 1
}
```

| Поле | Тип | Описание |
|---|---|---|
| `items` | CourseDto[] | Карточки курсов текущей страницы |
| `page` | integer | Запрошенный номер страницы |
| `pageSize` | integer | Запрошенный размер страницы |
| `totalCount` | integer | Число всех опубликованных курсов до пагинации |

При отсутствии опубликованных курсов `items = []`, `totalCount = 0`.
Для страницы за пределами каталога также возвращается `200 OK` с `items = []`;
`totalCount` при этом сохраняет общее число опубликованных курсов.

## GET /api/courses/{id}

Возвращает `200 OK` и объект `CourseDto` с карточкой курса.

Параметр пути `id` — GUID курса. Некорректный формат возвращает `400`;
отсутствующий, черновой или архивный курс — `404`.

### Пример запроса

```http
GET /api/courses/10000000-0000-0000-0000-000000000001
Accept: application/json
```

### Пример ответа

```json
{
  "id": "10000000-0000-0000-0000-000000000001",
  "title": "Основы PostgreSQL",
  "description": "Введение во внутреннее устройство PostgreSQL",
  "type": "course",
  "requiresAuthentication": false
}
```

`description` содержит сохранённое описание курса. Модули, темы и уроки
загружаются отдельным запросом структуры.

## GET /api/courses/{id}/structure

Возвращает `200 OK` и объект `CourseStructureDto` с полной структурой одного
опубликованного курса.

Параметр пути `id` — GUID курса. Некорректный формат возвращает `400`;
отсутствующий, черновой или архивный курс — `404`.

### Пример запроса

```http
GET /api/courses/10000000-0000-0000-0000-000000000001/structure
Accept: application/json
```

### Пример ответа

```json
{
  "id": "10000000-0000-0000-0000-000000000001",
  "title": "Основы PostgreSQL",
  "description": "Введение во внутреннее устройство PostgreSQL",
  "modules": [
    {
      "id": "20000000-0000-0000-0000-000000000001",
      "title": "Архитектура",
      "description": "Основные компоненты PostgreSQL",
      "sortOrder": 1,
      "topics": [
        {
          "id": "30000000-0000-0000-0000-000000000001",
          "title": "Процессы",
          "description": "Модель процессов сервера",
          "sortOrder": 1,
          "lessons": [
            {
              "id": "40000000-0000-0000-0000-000000000001",
              "title": "Главный процесс",
              "sortOrder": 1,
              "type": "lesson",
              "requiresAuthentication": true
            }
          ],
          "type": "topic",
          "requiresAuthentication": false
        }
      ],
      "type": "module",
      "requiresAuthentication": false
    }
  ],
  "type": "course",
  "requiresAuthentication": false
}
```

### Состав дерева

| DTO | Дополнительные поля к общим метаданным |
|---|---|
| `CourseStructureDto` | `description: string`, `modules: ModuleDto[]` |
| `ModuleDto` | `description: string`, `sortOrder: integer`, `topics: TopicDto[]` |
| `TopicDto` | `description: string`, `sortOrder: integer`, `lessons: LessonSummaryDto[]` |
| `LessonSummaryDto` | `sortOrder: integer` |

Модули, темы и уроки сортируются по `sortOrder` по возрастанию внутри своего
родителя. Значения порядка внутри одного родителя уникальны по ограничениям БД.

В ответе отсутствует `content` уроков. Метаданные опубликованных уроков видны
гостю, но чтение их содержимого требует JWT.

Пустые модули и темы сохраняются. Коллекции возвращаются массивами, включая пустые:
`modules: []`, `topics: []`, `lessons: []`. Структура курса не разбивается на страницы.

## GET /api/lessons/{id}

Возвращает `200 OK` и объект `LessonDto` с содержимым опубликованного урока.
Требуется действующий JWT.

Параметр пути `id` — GUID урока. Проверка авторизации выполняется до поиска
урока и валидации параметров контроллера. Без действующего токена ответ — `401`,
в том числе для отсутствующего урока или ID неверного формата.

Для авторизованного запроса некорректный GUID возвращает `400`.
Отсутствующий или неопубликованный урок, а также урок внутри чернового либо
архивного курса возвращает `404`.

### Пример запроса

```http
GET /api/lessons/40000000-0000-0000-0000-000000000001
Authorization: Bearer <accessToken>
Accept: application/json
```

### Пример ответа

```json
{
  "id": "40000000-0000-0000-0000-000000000001",
  "courseId": "10000000-0000-0000-0000-000000000001",
  "moduleId": "20000000-0000-0000-0000-000000000001",
  "topicId": "30000000-0000-0000-0000-000000000001",
  "title": "Главный процесс",
  "sortOrder": 1,
  "content": "Учебный материал о главном процессе PostgreSQL.",
  "type": "lesson",
  "requiresAuthentication": true
}
```

`courseId`, `moduleId` и `topicId` задают положение урока в дереве.
`content` возвращается как сохранённая строка, без преобразования разметки.

## Ошибки

| Код | Условие | Формат ответа |
|---|---|---|
| `400 Bad Request` | Неверный GUID или некорректные параметры пагинации | `ValidationProblemDetails` с полем `errors` |
| `401 Unauthorized` | Нет JWT либо токен неверен или просрочен при запросе урока | Ответ существующей JWT-аутентификации; тело может быть пустым |
| `404 Not Found` | Курс или урок отсутствует либо скрыт правилами публикации | `ProblemDetails` |
| `500 Internal Server Error` | Неожиданная ошибка, включая нетранзиентную ошибку БД | `ProblemDetails` |
| `503 Service Unavailable` | Транзиентная ошибка PostgreSQL/драйвера или таймаут | `ProblemDetails` |

`ProblemDetails` и `ValidationProblemDetails` возвращаются с типом содержимого
`application/problem+json`. Для этих методов нет отдельного сценария `403`:
опубликованные уроки доступны всем пользователям с действующим JWT.

Пример `404` для отсутствующего или скрытого курса:

```json
{
  "title": "Content not found",
  "status": 404,
  "detail": "The course was not found.",
  "instance": "/api/courses/10000000-0000-0000-0000-000000000001",
  "traceId": "request-trace-id"
}
```

Для урока поле `detail` содержит `The lesson was not found.`.
Скрытый и отсутствующий ресурс дают одинаковый ответ.

В ответах `500` и `503` содержатся общие сообщения об ошибке и `traceId`.
SQL, строка подключения и стек исключения клиенту не передаются. `traceId`
позволяет сопоставить ответ с серверным журналом ошибки.

Обработка исключений контента применяется только к `CoursesController`
и `LessonsController`. Формат ошибок остальных маршрутов определяется их
собственными обработчиками.

## Расположение реализации

Пути указаны относительно `backend/DBMSLab.Api`.

| Раздел | Файлы и ответственность |
|---|---|
| `Controllers` | `CoursesController.cs`, `LessonsController.cs` — HTTP-маршруты |
| `Application/Content` | `CourseService.cs` — публикация и формирование DTO; `ICourseRepository.cs` — контракт доступа к данным; `ContentReadModels.cs` — модели чтения |
| `Application/Content/Contracts` | `ContentContracts.cs` — DTO и параметры каталога |
| `Repositories/Persistence` | `CourseRepository.cs` — запросы EF Core через существующий `AppDbContext` |
| `Filters` | `ContentExceptionFilter.cs` — HTTP-ответы при исключениях контента |

Сущности EF Core и внутренние модели чтения напрямую в ответы API не попадают.

## Ограничения текущей модели

Исходная модель хранит публикацию, но не содержит отдельного признака открытого
гостевого доступа. Поэтому все опубликованные уроки требуют JWT; индивидуальная
настройка открытых уроков и наследование доступа не реализованы.

У урока нет отдельного краткого описания и состояния архива: в DTO отсутствует
`description`, а публикация определяется `IsPublished`.
Курсы имеют состояния `Draft`, `Published` и `Archived`.
